# boss-job-fetch

一个专门用来「攒岗位」的 Chrome 扩展。

在 BOSS 直聘上正常翻职位，它会把你浏览过的岗位自动记下来——标题、薪资、公司、城市，还有完整的岗位描述。看得差不多了，一键导出成 Excel 或 JSON，拿去对比、排序、跟进投递。

不用一条条复制粘贴，不用开着表格手工抄，也**不用登录任何账号**：所有数据只存在你自己的浏览器里，不经过任何服务器。

## 核心能力

- **边刷边存**：正常翻列表页就行，看过的岗位自动入库，不用点任何按钮
- **自动补齐完整 JD**：列表页只有职位、薪资这些摘要，扩展会把每条岗位的岗位描述（JD）单独抓回来补齐，历史遗漏的可以一键补全
- **一键导出**：导出 Excel 可直接打开的 CSV（不中文乱码）或 JSON，也能直接复制到剪贴板
- **数据能用**：薪资自动拆成月薪下限、上限、几薪；乱码薪资会被过滤；抓不到的岗位标出原因，可重试、可清理已下架岗位
- **纯本地**：数据只写在浏览器本地存储，不注册、不上传、不同步

## 安装

1. 下载或克隆本仓库到本地
2. 打开 `chrome://extensions/`
3. 右上角开启「开发者模式」
4. 点击「加载已解压的扩展程序」，选择本目录
5. **刷新已打开的 BOSS 直聘页面**（内容脚本只在页面加载时注入）

## 使用

| 操作       | 位置        | 说明                                   |
| -------- | --------- | ------------------------------------ |
| 自动采集     | 浏览职位列表页   | 自动拦截列表接口并入库，无需点击                     |
| 补全 JD 正文 | 弹窗主按钮     | 逐条抓取详情页，只处理缺正文或薪资异常的记录               |
| 自动补全     | 弹窗勾选框     | 打开 BOSS 页面时自动补最多 20 条，适合日常挂机         |
| 重试失败记录   | 弹窗次级按钮    | 重置被熔断的记录，重新入队                        |
| 清理已关闭岗位  | 弹窗次级按钮    | 删除「岗位已关闭且无 JD」的记录，需两次点击确认            |
| 快速提取     | 弹窗按钮      | 从当前页面 DOM 抓标题 / 薪资 / 公司 / 地点，接口失效时兜底 |
| 导出数据     | 弹窗「打开数据页」 | JSON / CSV / 复制到剪贴板                  |
| 表格排序     | 数据页表头     | 点击表头排序，再点切换升降序，第三次恢复采集顺序；导出跟随当前排序    |
| 数据体检     | 数据页       | 检查薪资可解析率，异常项显示原文与 Unicode 码位         |
| 清空数据     | 弹窗 / 数据页  | 清除本地全部记录                             |

补全过程中请保持 BOSS 标签页在前台，抓取速度为每条 0.7–1.5 秒，每 10 条额外休息 5–9 秒。

## 数据字段

| 字段                                          | 含义                                        |
| ------------------------------------------- | ----------------------------------------- |
| `id`                                        | 岗位 ID（encryptJobId）                       |
| `title` / `salary` / `company` / `location` | 职位、薪资、公司、城市·区域                            |
| `salaryMin` / `salaryMax` / `salaryMonths`  | 由薪资文本解析出的月薪区间与月数                          |
| `salaryStatus`                              | `ok` / `negotiable` / `invalid` / `empty` |
| `experience` / `education` / `skills`       | 经验、学历、技能标签                                |
| `industry` / `scale` / `stage`              | 行业、公司规模、融资阶段                              |
| `description`                               | JD 正文（截断 3000 字）                          |
| `detailSource`                              | `detail-page` / `click-panel` / `failed`  |
| `detailAttempts`                            | 抓取失败次数，满 3 次不再自动重试（成功即清零）                 |
| `detailError`                               | 失败原因码，见下表                                 |
| `url`                                       | 详情页链接                                     |
| `crawlTime` / `updateTime`                  | 首次采集 / 最后更新时间                             |

同 id 的记录按字段并集合并，列表摘要与详情正文会落在同一条记录上。

## 失败原因

数据页「来源」列直接显示原因：

| 码                | 含义              | 是否自动重试          |
| ---------------- | --------------- | --------------- |
| `security`       | 命中安全验证          | 是               |
| `login`          | 需要登录            | 是               |
| `rate-limit`     | 请求过快被限流         | 是               |
| `network`        | 请求异常            | 是               |
| `short`          | 返回内容为空          | 是               |
| `iframe-timeout` | 页面加载超时          | 是               |
| `empty`          | 页面打不开或找不到 JD 正文 | 是（满 3 次停）       |
| `closed`         | 岗位已关闭 / 下架（终态）  | 否，可用「清理已关闭岗位」删除 |

环境类失败（`security` / `login` / `rate-limit` / `network` / `short` / `iframe-timeout`）不计入失败次数；连续 3 次环境类失败会中断当前批次，剩余记录保持待补状态。

## 目录结构

```
manifest.json      扩展配置（权限：storage / scripting + zhipin.com 主机权限）
interceptor.js     主世界接口劫持，解析列表数据
content.js         采集与补全引擎
background.js      存储与队列管理
popup.html/js      弹窗界面
export.html/js     数据页与导出
icon.png           图标
dev/               早期调试脚本，不参与打包
.gitignore
```



## 注意

- 仅作个人求职用途，请遵守 BOSS 直聘用户协议，保持克制频率。
- 采集依赖已登录会话，未登录状态下详情页会返回 `login`。
- 站点改版可能导致选择器失效，接口路径变化时修改 `interceptor.js` 中的 `URL_HINTS`。
